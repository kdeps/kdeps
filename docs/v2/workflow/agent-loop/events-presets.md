# Event presets

An override file changes or turns off one [event](/workflow/agent-loop/events). A preset is a named set of overrides.

```yaml
# ~/.kdeps/events/identical-tool-calls.yaml (or events/ in the workflow project)
name: identical-tool-calls
disabled: true
```
