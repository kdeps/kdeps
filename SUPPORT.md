# Support

Need help with kdeps? Use the channel that fits your question.

| I want to... | Go to |
| :--- | :--- |
| Read the docs | <https://kdeps.com> |
| Browse the component registry | <https://kdeps.io> |
| Ask a "how do I..." question | [GitHub Discussions](https://github.com/kdeps/kdeps/discussions) |
| Report a bug | [GitHub Issues](https://github.com/kdeps/kdeps/issues/new/choose) |
| Request a feature | [GitHub Discussions](https://github.com/kdeps/kdeps/discussions) |
| Report a security issue | [Security policy](SECURITY.md) - do not open a public issue |
| Report a code of conduct issue | conduct@kdeps.com |

## Before you ask

- Check the [documentation](https://kdeps.com), especially the
  [troubleshooting guide](https://kdeps.com/guides/troubleshooting) and the
  [FAQ](https://kdeps.com/guides/faq).
- Search [existing issues](https://github.com/kdeps/kdeps/issues) and
  [discussions](https://github.com/kdeps/kdeps/discussions).
- Run `kdeps doctor` and include its output.

## Filing a good bug report

Include the kdeps version (`kdeps --version`), your operating system, the
`workflow.yaml` (or a minimal reproduction), the exact command you ran, and the
full output with `--debug`.

## Response expectations

kdeps is maintained by a small team. Issues and discussions are triaged on a
best-effort basis. There is no paid support tier.
