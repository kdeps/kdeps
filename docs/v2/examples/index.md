# Examples

Each example is a complete project. Copy its files and run the command on its page. A local model needs no API key.

| Example | What it builds |
|---|---|
| [Document summarizer](/examples/file-processor) | Reads one file and returns a JSON summary |
| [Batch processing](/examples/batch-processing) | Processes a list of items in one request |
| [Document search (RAG)](/examples/rag-search) | Indexes documents and searches them |
| [Login and sessions](/examples/session-auth) | A login that starts a session |
| [Shell command API](/examples/shell-command-api) | Runs a shell command over HTTP |
| [Function calling](/examples/function-calling) | A model that calls your resources as tools |
| [Image analysis](/examples/vision) | Describes an uploaded image |
| [SQL-backed API](/examples/sql-api) | Queries and updates a database |
| [Chat web app](/examples/chat-web-app) | A chat API and its web page |
| [File upload](/examples/file-upload) | Accepts file uploads |
| [Design review panel](/examples/design-review) | Parallel reviewers for a design document |
| [Conditionals and lists](/examples/control-flow) | Expressions for conditions and lists |
| [Authenticated API call](/examples/http-auth) | Calls an API with a token, retry and cache |
| [MCP server tools](/examples/mcp-tools) | Tools from an MCP server |
| [Inline resources](/examples/inline-resources) | Actions inside `before:` and `after:` |
| [Local file search](/examples/local-file-search) | Searches files on disk |
| [Python data processing](/examples/python-processing) | Converts data with a Python script |
| [Static site](/examples/static-site) | Serves static files |
| [Telegram bot](/examples/telegram-bot/) | A Telegram bot on a local model: a listener in, a connector out |
| [Showcase](/examples/showcase) | Short agents for common tasks |
| [Two-agent agency](/examples/agency) | One agent that calls another |
| [Reusable component](/examples/custom-component) | A component you build and call |
| [Per-component env vars](/examples/component-env) | A different env value for each component |
