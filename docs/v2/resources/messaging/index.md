# Messaging resources

Three resources for reaching a person. Each has its own reference page.

*Applies to both workflow mode and agent mode.*

| Resource | Channel | Reference |
| :--- | :--- | :--- |
| `email:` | SMTP send, IMAP read / search / modify | [Email](/resources/messaging/email) |
| `telephony:` | Voice calls - say, ask, menu, dial, record | [Telephony](/resources/messaging/telephony) |
| `botReply:` | Reply to the chat platform that delivered the message | [Bot reply](/resources/messaging/bot-reply) |
