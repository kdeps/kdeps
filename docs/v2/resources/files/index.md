# File resources

Two resources for local files and version control. Each has its own reference
page.

*Applies to both workflow mode and agent mode.*

| Resource | Does | Reference |
| :--- | :--- | :--- |
| `file:` | Read, write, patch, list, delete, copy, move files and directories | [File](/resources/files/file) |
| `git:` | Status, diff, log, commit, branch, push, pull on a repository | [Git](/resources/files/git) |
